Interactive API Documentation

Transforma exposes a direct, high-performance HTTP REST API for bidirectional conversion. You can programmatically access the following endpoints:

POST /api/v1/convert/json-to-xml

Converts raw JSON payload into structured XML document.

Query Parameters:

Parameter Type Default Description
root string root Root XML tag name
array_mode string wrapper Array format: wrapper or repeating
attr_prefix string @ Prefix indicating XML attributes in JSON keys
pretty boolean true Pretty-print indenting output

Example Request (curl):

curl -X POST "https://json-xml-parser-m9o2.onrender.com/api/v1/convert/json-to-xml?root=user&array_mode=wrapper" \
     -H "Content-Type: application/json" \
     -d '{"@id": 12, "name": "Alice", "skills": ["Go"]}'
POST /api/v1/convert/xml-to-json

Converts raw XML payload into structured JSON.

Query Parameters:

Parameter Type Default Description
attr_prefix string @ Prefix for XML attributes in the output JSON
text_key string #text JSON key for text node content alongside attributes/children
auto_type boolean true Parse numeric/boolean values from strings automatically
pretty boolean true Pretty-print indenting output

Example Request (curl):

curl -X POST "https://json-xml-parser-m9o2.onrender.com/api/v1/convert/xml-to-json?auto_type=true" \
     -H "Content-Type: application/xml" \
     -d '<user id="12"><name>Alice</name><skills><item>Go</item></skills></user>'
